# ComfyUI-Slot-Position

Permite reposicionar **visualmente** os slots de qualquer nó do ComfyUI
(topo, esquerda, direita, baixo, cantos).

**Backend 100% inalterado.** É puramente uma camada visual em cima do LiteGraph.

## Instalação

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/SEU_USUARIO/ComfyUI-Slot-Position.git
